## Standards

### 硬规范

- **[P2] 查询响应未完整执行有界展示契约。** `src/batches.js:24-25` 通过 `({analysis,...source})=>({...source,...})` 保留 Inbox 的完整 `segments`（来自 `src/inbox.js:62` 的 `...entry`），且分页只处理 preview/historicalResult/validationResult/authorization，遗漏 `archiveResult.items`。因此 `limit:1` 仍可返回整篇长文的所有分段证据或完整归档清单。违反 `docs/batches-contract.md:19`：“查询按 cursor,limit 分页来源和分批明细……每页最多 50 项，原文证据有界展示。”修正：公共来源采用字段白名单，统一裁剪证据；归档明细纳入分页，并补长文及超过 50 项的响应边界测试。

### 主观判断（Fowler 启发式，非硬规范）

- **[P3] 可能的 Duplicated Code。** `public/inbox.js:3-5` 重写状态字典和“取会话→POST→解码错误”；`public/batch-ui.js:1-3` 已提供相同职责的 `statusName/requestBatch`。两个批次入口修复状态或错误协议时需同步修改，且目前错误对象保留字段不同。复用已有请求函数与共同状态表，仅保留 Inbox 特有状态覆盖。

- **[P3] 可能的 Speculative Generality。** `src/migration-policy.js:3-14` 仍保留“后续……替换这些独立策略”的旧拒绝占位；全仓引用检索只命中定义。`src/migration.js:20` 的 `relativeRaw`、`src/shared-outputs.js:17` 的单源 `migrateAllCacheOutputs` 同样无调用者，而批量实现已有替代路径。删除这些过渡实现，避免后续维护者误选会全拒绝或不支持批量交换的旧入口。

结论：1 项硬规范偏差，2 项主观可维护性建议；最严重为批次查询响应边界未遵守文档契约。

## Spec

基线 `956fcf5...9ae5b70`；按 Spec #1 及 T1–T13 检查。以下为静态确认的可触发缺陷，不以既有测试通过替代边界证明。

1. **[P1，实现错误] 新来源冻结后变成历史，仍可直接归档。** 规格：“历史材料与新材料根据已摄取记录及关联状态区分”“审核后的源状态变化应使相关计划失效”。`src/batches.js:30` 仅检查旧 ingestStatus 和文件哈希；`src/inbox.js:146` 丢弃重新发现的状态。库内 Inbox 在 prepare 后被 Wiki 摄取、队列结束且正文未变时，apply 仍走 copy/unlink，绕过 T2/T6/T8，遗留缓存与快照。修复：最终写入前逐项比对当前摄取身份及关联摘要，不一致使分批失效；加入冻结后新增 cache/Wiki 关联的公开批次回归。

2. **[P1，实现错误] 恢复续作可覆盖中断后的用户状态。** 规格：“覆盖前保留失败现场及迁移后新增内容，不能盲目回滚丢弃后续数据”。`src/recovery.js:123` 每次 final-bind 都无条件 resetState。该步骤完成写入、尚未记录 completed 时退出，用户随后修改恢复目录 project.json／cache，续作会覆盖这些修改且不保留新现场。修复：绑定前核验当前字节属于已记录的前态或后态；其他变化停止或另外保存现场，并测试 final-bind 中断后的状态修改。

3. **[P2，需求部分缺失] 首次分类树没有程序化排除同义类别。** 规格：“程序校验模型建议，排除……同义类别”。`src/restructure.js:42` 只匹配同父目录的字面名称，忽略 aliases 和跨分支同义类别；已有 Agent（alias AI Agent）时仍会创建 AI Agent。修复：复用全目录及 aliases 索引；重复提议复用或拒绝，补跨分支回归。

4. **[P2，需求部分缺失] 新文件归档会改变有效相对链接目标。** 规格：“受影响的本地相对链接继续指向原目标”“附件不主动重新分类”。`src/inbox.js:154–158` 原样复制后删源，没有链接基线或修正；外部 Inbox 的 `![图](image.png)` 移入 Raw 后指向另一目录。修复：冻结等价链接修正并审核，或对无法安全迁移的来源保留并报告；覆盖图片和材料间相对引用。

未发现需要另行批准的功能扩张。支持版本及未知格式拒绝、备份/副本/原库分离、模型出口守卫、向量保留等主流程已有实现；上述缺陷仍违反其安全边界。
