## 浏览器交互证据

- 首页的“继续审核”只进入已有任务；首次重构保留独立范围与入口。
- 阅读材料与勾选独立；人工修改名称后切到其他材料再返回，草稿保留。详情默认收起，关闭后焦点回到“详情”。
- 零选中隐藏执行栏，多选显示跨全部页面的明确范围。未确认暂停写入时按钮禁用，请求期间禁用重复提交。
- 合成环境实际归档一份人工命名的材料：报告显示成功 1、保留 11、失败 0；磁盘核验目标文件存在、原收件箱文件消失、其余 11 份仍在收件箱。未选中项在报告中明确标为保留原处，证据不足项保留真实原因。见[报告](screenshots/report.jpg)。
- 分类展开与选中独立，Raw 根目录可选；路径默认收起，长路径可换行。窄屏文档宽度与视口内容宽度相同，没有全页横向溢出。
- 键盘 Enter 选择分类后，请求完成仍聚焦该分类按钮且有可见轮廓；[焦点截图](screenshots/B4-keyboard.jpg)。归档反馈存在时，库选择器进入正常文档流，不遮挡结果标题；没有反馈时维持 B2 阅读布局。
