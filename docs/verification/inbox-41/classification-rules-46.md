已验证默认修改仅作用当前文件；明确勾选并填写后续规则才保存。连续材料的分类检索与选择读取同库规则，另一真实知识库不继承，服务重启保留；相同位置更换项目后不能续用旧规则。类别失效、正文引用不足或未人工审核时仍不能归档，规则保存不创建目录、不移动历史材料。

规则变化使旧分类和冻结授权需要复核；正文分段及汇总调用数保持不变。公开 `reviewBasis.rulesHash`、`effectiveRulesHash` 与最新规则独立核验，旧依据保存返回 `STALE_REVIEW`。在途分类若规则变化，迟到结果不写成当前建议；手动继续仅补分类。DOM 验证规则、分类输入使用同一草稿，刷新保留文本框节点、焦点与光标，审核请求携带用户所见依据。

已接受新类别的偏好保存为待生效规则，重启后保留。实际目录缺失或提议证明不匹配时不进入模型；明确确认归档后才创建类别并激活偏好，后续材料仍须审核。公开回归确认激活、失活时原 `rulesHash` 可以不变，但有效摘要变化会使旧自动结果仅重做分类。同提议两份所选材料可以协调归档，类别仅创建一次，规则激活不撤销同次人工授权；其他旧审核按规则版本撤权、未选材料保留原处。
